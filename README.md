# Operator-Specific Forgetting in Matrix-Valued Associative Memory

**Author**: Javier Escobar - Independent Researcher
**Version**: v1.0.0 - **Date**: 2026-08-21 - **Source commit**: `cec4ffe` (tag `lab-radioactivo-v1`)

This package contains the code, data, and verification report for a controlled
study of selective forgetting in matrix-valued associative memories. It is the
reproducibility artifact for the preprint *Operator-Specific Forgetting in
Matrix-Valued Associative Memory* (see `paper/`).

## 1. What question does this work answer?

> When a linear associative memory erases one of its stored associations, how
> much of the erased item remains in the state, as a function of the **storage
> operator** (phasor-superposition vs. delta-rule), the **read channel**
> (complex vs. real), and the **type of drift** (key drift vs. state drift)?

The answer is four closed-form residual laws with **zero free parameters**,
verified on *trained* models at two dimensions (d=64, d=128) while holding the
load `c = (n-1)/D` fixed.

## 2. What was demonstrated

1. **Forgetting is usually measured worse than retrieval.** Power leakage
   (`fuga = E||r||^2/E||v||^2`) understates *functional* leakage by more than
   an order of magnitude: under key drift at delta=0.2 the residual decodes at
   43% EM (exact match of a trained readout head) with a power leakage of 0.018.
2. **Energy leakage is not functional leakage.** Only one cell of the
   2x2 grid (key/complex) has true erasure: the residual is *exactly zero*
   (null-residual guard, 6 delta x 5 seeds). The other three cells leave a
   structured copy of the erased value that a trained readout head decodes.
3. **The residual depends on the operator and the drift type** (four distinct
   closed forms, no free parameters):

   | cell | law | d=128 max deviation (5 seeds x 6 delta) |
   |---|---|---|
   | key drift / complex channel | 0 (flat, exact) | 0.0000 |
   | state drift / complex channel | 2(1-cos delta)(1+c) | included in 0.0049 |
   | key drift / real channel | sin^4(delta) + c(1-cos 2delta)/4 | included in 0.0049 |
   | state drift / real channel | (1-cos delta)^2 + c(1-cos delta) | included in 0.0049 |

   Global bound: max |measured - pred| over seeds = **0.0049** (criterion < 0.02).
4. **The laws are a function of the load c = (n-1)/D, not of D**: re-running
   the probe at d=64 with matched c = 0.3047 gives per-cell diff <= 0.0064
   (4/4 cells).
5. **LMS stability of the corrective write**: superposition write is open-loop
   (unconditionally stable); corrective write is stable iff beta||k||^2 < 2.
   beta=1 with ||k||^2=8 diverges (||S|| ~ 10^11); NLMS normalization
   (||k||=1) trains forget_retrieval to EM 1.000.
6. **Erase selectivity does not discriminate operators at this scale**: TOST
   (two one-sided equivalence test) on selectivity (wave_complex vs.
   delta_nlms, d=128, 5 seeds) gives mean
   -0.0031, IC90 [-0.0206, 0.0144] -- *almost-equivalent*, crossing eps=0.02 by
   0.0006, reported unrounded (8-10 seeds would likely close the margin; no
   power analysis was run). The claim lives in the *shape of the leakage*
   (the four laws), not in erase EM.
7. **Lineage theorem**: complex re-read erase `M - w(w^H M)/D` is exactly the
   delta-rule projection with beta=1 (diff 0.0). The equivalence is a theorem,
   reported as lineage, not superiority.

**Main result**: exact erasure is a property of the *projector* with a fresh
key (absolute guarantee under clock drift, copy-decodable under state drift),
not of the operator. In v1 (fixed codebook, non-oscillating state) neither
drift occurs naturally: the 2x2 grid is a stress test that delimits where the
guarantee lives, not an operational failure mode.

## 3. What was NOT demonstrated

- No retrieval claim: this work does not claim that interference memory beats
  attention on MQAR-style (multi-query associative recall) retrieval (the
  binding law L-056/L-064 of the source lab -- internal claim IDs -- still
  holds; the attention anchor on forget_retrieval at d=64 is 0.067).
- No new VSA/HRR mechanism: phasor superposition, matched-filter reading and
  unbinding are Plate/Kanerva/Frady formalism. The novelty is the *forgetting
  axis*: the formalization of the post-erase residual under drift with learned
  keys/values, the exact equivalence to the delta rule, and the matched-budget
  measurement.
- No TinyStories / language scaling (out of budget; claims are scoped to
  d=64/d=128 on the lab harness).
- No hardware throughput/energy claims (CPU/GPU kernels were not benchmarked).
- The TOST is *almost*-equivalent: its 90% CI crosses the 0.02 margin by
  0.0006. 8-10 seeds would close it.
- Learned-key regime (v2) is deferred; EM is saturated (1.000 x 15 combos) and
  is used as sanity only -- the probes carry the evidence.

## 4. What is new vs. the lineage

| Part | Attribution |
|---|---|
| Phasor superposition, matched filter, unbinding, capacity | HRR/VSA -- Plate 1995, Kanerva, Frady et al. |
| Delta rule as fast-weight programmer; beta gates | Schlag et al.; DeltaNet / Gated DeltaNet (Yang et al.) |
| LMS/NLMS corrective loop; condition beta\|\|k\|\|^2 < 2 | Widrow-Hoff LMS/NLMS |
| Post-erase residual laws under key/state drift (2x2 grid) | **This work** |
| Exact equivalence complex re-read erase == delta-rule beta=1 | **This work** (bridge VSA -> delta rules) |
| Matched-budget measurement of the forgetting axis | **This work** |
| Conditional erasure guarantee (clock coherence) | **This work** |
| Stability reading of DeltaNet beta gates (LMS condition) | **This work** (reading, not a new gate) |

## 5. Reproduce

### Requirements

- Python 3.10+ with PyTorch (CPU-only is enough for the probes; training the
  d=128 O05 arms needs a GPU, ~5.4h on 2xT4).
- Quick checks run on a regular laptop (i3 8GB class, ~30 min CPU for the
  d=64 smoke).

### Verify integrity (optional)

```bash
sha256sum -c MANIFEST.sha256        # Linux/macOS
# Windows PowerShell (fails with exit code 1 on any mismatch):
#  $bad = 0; Get-Content MANIFEST.sha256 | ForEach-Object { $h,$f = $_.Split('  ',2); if ((Get-FileHash $f -Algorithm SHA256).Hash.ToLower() -ne $h) { "FAIL: $f"; $bad++ } }; if ($bad) { exit 1 } else { "all OK" }
```

### Quick start (probes on included checkpoints -- minutes on CPU)

```bash
pip install torch
python tests/o04b_run.py            # 2x2 laws on trained d=64 models (3 seeds)
python tests/o04_run.py             # 2x2 x delta grid (O04)
python tests/n1_heldout_check.py    # held-out generalization check (fresh keys)
python paper/verify_numbers.py      # recompute every number quoted in the paper
```

All probes read the trained checkpoints shipped in `outputs/` (no training
needed). Verify against the shipped JSONs in `outputs/wave_mem/`.

### Full O05 (d=128, the gate result)

- **Training + probe, GPU**: `python tests/wave_mem_smoke128.py --device cuda`
  (5 seeds x 3 arms; wave 60ep x 600, delta_nlms 150ep x 1200; ~5.4h on 2xT4
  with two workers, ~12h on one GPU; CPU is not practical for training).
- **Exact execution artifact**: the self-contained Kaggle kernel
  `kaggle/onda_o05.ipynb` (javierezcobar/onda-o05, kernel v5, COMPLETE in
  19510s on 2xT4, 2 workers seeds 1-3 | 4-5, JSONs merged). It embeds the code
  and the d=64 checkpoints, and regenerates `outputs/wave_mem/o05.json`.
- **Probe-only re-verification on CPU**: the same script with the shipped
  d=128 checkpoints resumes training (skips completed arms) and re-runs the
  2x2/C1/TOST probes in minutes.

### Figures (regenerate from frozen JSONs)

```bash
pip install matplotlib scipy
python paper/make_figures.py        # writes figures/*.pdf and *.png
```

### d=64 N1 smoke (full retraining from scratch, CPU ~30 min)

```bash
python tests/wave_mem_n1.py --seeds 1,2,3   # 5-task smoke, 3 seeds
python tests/transformer_smoke.py --save-baseline   # frozen attention anchor
```

### O05 exact configuration (frozen)

- Data: `forget_retrieval` only, 600 train / 128 valid, n_pairs (32,48),
  n_forget (1,2), max_seq_len 112, key space 48 keys / 48 vals (vocab 105).
- Model: d=128, 2 layers, AdamW lr=1e-3 wd=0.01 clip=1.0, seeds 1..5.
- Probe: 320 events/arm/seed, cells {key,state} x channels {complex,re},
  delta in {0, .1, .2, .3, .4, .5}, pooled fuga, c = 39/128 = 0.3047,
  null-residual guard eps=1e-4, TOST eps=0.02 IC90 t(0.95,4)=2.132.
- Budget by family: wave 60ep x 600 (saturates EM 1.000), delta_nlms
  150ep x 1200 (the d=64 n1 recipe).
